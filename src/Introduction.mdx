# Design System

React + Tailwind CSS v4 component library.

| Component | Variants |
| --- | --- |
| **Button** | primary, secondary, outline, ghost, destructive, link · sm/md/lg · loading, icons |
| **Input** | outline, filled, underline · sm/md/lg · helper, error, icon |
| **Dropdown** | outline, filled, ghost · single & multi-select · descriptions |
| **Badge** | solid, soft, outline × neutral/brand/success/warning/danger · dot |
| **Alert** | soft, solid, accent × info/success/warning/danger · dismissible, action |
| **Card** | elevated, outlined, filled, interactive · media layout |
| **Avatar** | image, initials, placeholder · circle/square · xs–xl · status · group |
| **Checkbox** | default, rounded, card · brand/success/danger · indeterminate |
| **Toggle** | brand/success/danger/neutral · sm/md/lg · icons, label position |
| **Tabs** | underline, pills, segmented · counts, disabled |
| **Modal** | dialog, drawer · sm/md/lg/full · default/danger/success |
| **Tooltip** | dark, light, brand · top/bottom/left/right · arrow |
| **Accordion** | default, bordered, separated · single or multiple open |
| **Radio** | default, card, button group · vertical/horizontal · sm/md/lg |
| **Textarea** | outline, filled, ghost · character counter, error · resize modes |
| **Progress** | bar, striped, circle × 4 tones · indeterminate |
| **Spinner** | ring, dots, pulse · 5 sizes · 5 tones |
| **Skeleton** | text, rect, circle · pulse/shimmer · card & list placeholders |
| **Breadcrumb** | default, contained · chevron/slash/dot · home icon, collapsing |
| **Pagination** | default, outline, ghost, simple · sm/md/lg |

Brand color tokens live in `src/index.css` under `@theme` (`--color-brand-*`). Change them there to re-theme every component.
